# 使用和整理自己的风格

公开版附带 `basic-editorial` 基础排版，包含正文、标题、引用、图片、图注、列表和代码等组件。它帮助你先完成一篇文章，之后再调整自己的表达和布局。

## 查看已有风格

```powershell
.venv/Scripts/python -m wechat_studio_cli --workspace .local/workspace style list
```

项目中的样式选择记录 ID、版本与所在层。新版本可以继续发布，旧文章仍引用原版本，方便重新打开。

## 从参考文章整理特点

选几篇希望分析的文章，说明喜欢的部分，也说明不想沿用的部分。风格提取 skill 会帮助登记参考、比较文字结构和页面样式，并生成候选。

只有文字的材料可用于分析写作特点；字号、间距与排版需要包含对应样式的 HTML。参考样本与分析结果保存在你选择的本地工作区。

## 导入与确认

风格库 skill 可以检查候选、导入本地库，并在确认后保存新版本。一个预设可以组合排版与写作档案；归档保留历史文件，使旧文章可以继续读取。

原有的参考账号模板、私人风格库、文章和页面快照没有收入公开版。你可以在自己的工作区使用有权使用的素材，发布或分享时分别确认其许可。

公开工具的基础 HTML 组件属于运行资源；它们也为新生成的样式提供可调整的起点。
